# Changelog

## 1.8 — 2026-11-04

- Full-bleed blue icon artwork to avoid an inset tile appearance on current macOS.
- Standalone Apple Silicon package with libmtp and libusb included.

## Earlier development builds — 2026-11-04

- Native file list and direct MTP downloads, avoiding a Finder mount.
- Batch progress, average speed and time remaining.
- Explicit checkboxes, Select All and Clear.
- Automatic connection checking stops after successful connection.
- Destination names use `P1-recordings-yyyyMMdd-HHmmss`.
- Clear hidden flags on completed downloads.
- Preserve original files on the P1 and keep completed downloads on later failure.

The first public source release collects these development changes. Hardware and macOS coverage remain limited; see README.
